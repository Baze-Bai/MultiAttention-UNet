# Source provenance

This independent public repository contains an allowlisted source snapshot of Zejun Bai's MultiAttention_Unet project. Its original private repository, identity, visibility and commit history are retained unchanged.

The export omits datasets, sample images, trained models, pickle files, notebook outputs, generated media and the original Git history. It retains the two source architecture variants and corrects package references only in the public copy.

PyTorch, torchvision, scikit-learn, scikit-image, Streamlit, Pillow, Hugging Face Hub and other dependencies remain subject to their respective licenses. No dataset or external-model redistribution rights are implied.
